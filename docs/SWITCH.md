# Nintendo Switch: see the `switch` branch

The 3DS port grew out of an early copy of the Switch port, and this branch still carries
that copy (`src/SB/Core/pc/switch`, `tools/switch`, `dist/switch`). It is older than the
Switch port and is not kept up to date here.

For the Switch, use the **`switch` branch**: its code is current and its `docs/SWITCH.md`
is the guide (building, playing, controls, what has been checked on a console).

For the 3DS, see `docs/3DS.md`.

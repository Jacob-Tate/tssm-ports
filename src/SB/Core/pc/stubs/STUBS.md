- **stub**: the body calls `IPORT_STUB()` and prints `[pcport] not implemented: <name>` the
  first time it runs, so a run log names the stubs that session reached.
- **module stub**: a function of a module whose header calls the whole file a stub; most of
  these are silent.

  whole PC surface is in one place.
